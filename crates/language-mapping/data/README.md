# Mapping data and license scope

`registry.json` is generated by `scripts/import_mapping_data.py`. Production
builds embed it and make no network requests. Schema v1 sources, schemes and
individual rules retain separate provenance; the containing crate's MPL license
does not relicense the imported material.

- CLDR transform files and derived kana/Russian/Han rules: **Unicode-3.0**.
  Copyright Unicode, Inc.; retain `upstream/cldr-LICENSE`. Its opening restriction
  concerns the LDML specification publication. The notice explicitly licenses
  all other repository data/software under Unicode License v3. We copy data,
  not the restricted specification text. Subsets are named as project subsets,
  not full ICU conformance, ISO 9 or generic Hepburn implementations.
- Selected original CMUdict lines, pronunciation inventory and derived English
  entries: **BSD-2-Clause**, copyright 1993–2015 Carnegie Mellon University;
  retain `upstream/cmudict-LICENSE`. 443 selected spellings contain 549 distinct
  pronunciations; 91 spellings have multiple variants. The ARPAbet→IPA code
  is an original MPL adapter and does not make those encodings interchangeable.
- Selected IANA Protocol Registry records: **CC0-1.0** under the IANA/IETF joint
  statement dated 2021-11-10: https://www.iana.org/help/licensing-terms .
  The full source snapshot File-Date is 2026-09-17; only relevant records are kept.
- Selected ISO 15924 Registration Authority facts come from Unicode's public
  code list; retain Unicode notices. No paid ISO romanization publication is
  included. Script code `Zyyy` denotes Common notation here, not a claim that
  IPA is a separate writing system or that all IPA symbols have that property.
- Original registry descriptions and this data documentation: **CC-BY-4.0**,
  Stya Yur Open Source Studio. Conversion algorithms and schema code: **MPL-2.0**.
- Test pronunciation facts from Wiktionary have per-entry URLs and attribution
  in `tests/fixtures/external.json`; any copyrightable excerpts retain
  **CC-BY-SA-4.0**. They are test references, not a bundled production lexicon.

`sources.json` records exact hashes, dates, URLs, versions and copied/transformed
scope. `check_mapping_data.py` verifies every byte and reference in CI.
`upstream/` files retain their original bytes; do not normalize their line endings.
CLTS, PHOIBLE, Epitran, UNGEGN, ALA-LC, IPA charts and SSML are research references,
not imported production rules. Their file-specific license assessment is in
`docs/research/authority-sources.json` and does not grant redistribution rights
to unrelated files or charts.
