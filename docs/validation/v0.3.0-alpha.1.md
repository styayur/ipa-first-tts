Native evidence is in `v0.3.0-alpha.1-native.json`. The Windows helper returned
`GetCursorPos: access denied (0x80070005)` while launching a fresh editor. A
recovered palette handle did not yield reliable usable desktop state. No input
was retried against stale/blank state, and no raw UI automation bypass was used.
The new Release palette was launched with an isolated config and a distinct
Ctrl+Alt+Shift+F6 test shortcut. The user confirmed read candidates, kōhī, Han polyphony/context, Russian romanization, Copy, palette composition and editor insertion. These are user tests of the recorded candidate hash; specific editor/tray/exit regressions and extracted-package tests remain pending. Prior
v0.2 editor/browser/tray checks are historical, not relabeled as this version.

Hidden native controls verify bounds at three sizes, conversion completion,
selected candidate transfer values and Chinese labels without foreground,
clipboard or global input actions. Native mutex/registration tests cover OS API
semantics. These are scoped automated checks, not real editor/tray/DPI passes.

Both package scripts preserve existing versions and refuse final assets until
all existing native gates plus mapping UI/Copy/composition gates pass for the
recorded version/commit. Explicitly suffixed local candidates retain unverified
evidence. Final merge-commit builds, ZIP inventory/CRC/SHA verification, public
GitHub download and fresh-extraction runtime checks remain release-stage work.

No signed executable, physically disconnected network, independent clean VM,
mixed-monitor/150%/200% DPI, higher-integrity target, remote/full-screen editor,
or non-English synthesis is claimed.
